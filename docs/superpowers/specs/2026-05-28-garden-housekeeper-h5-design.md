# 花园管家 H5 设计说明

## 目标

构建一个个人使用的花园管家 H5 页面，用于记录每盆花的浇水和施肥情况，并根据用户设置的周期自动计算下次养护日期。首页需要快速展示逾期、今天、未来 3 天内需要浇水或施肥的花。

## 产品定位

MVP 定位为“轻量花草档案 + 今日养护清单”。重点是：

- 快速看到最近需要照顾的花。
- 快速记录浇水或施肥。
- 为每盆花保留养护历史。
- 使用浏览器本地保存，不要求登录或云同步。

## 页面结构

### 首页：养护手账

首页用于查看近期养护任务。

包含：

- 顶部状态卡，显示类似“今天有 3 件养护小事”的状态文案。
- 分段切换：逾期、今天、未来 3 天。
- 任务列表，每条任务代表一次养护事项，而不是一盆花。

任务卡显示：

- 花名。
- 任务类型：浇水或施肥。
- 日期状态：今天、已逾期几天、几天后。
- 快捷完成按钮：已浇水或已施肥。

点击任务卡可以进入对应花草详情页。

### 花草档案页

档案页展示所有花草。

每张花草卡片显示：

- 名称。
- 可选图片。
- 下次浇水日期。
- 下次施肥日期；如果关闭施肥，则不显示施肥提醒。

页面提供新增花草入口。

### 花草详情页

详情页展示单盆花的信息和历史记录。

包含：

- 名称、图片、浇水周期、施肥周期。
- 快捷按钮：记录浇水、记录施肥。
- 历史记录时间线，按日期倒序展示。
- 编辑花草信息入口。

## 数据模型

每盆花包含：

- `id`：唯一标识。
- `name`：名称，必填。
- `image`：图片，可选。
- `wateringIntervalDays`：浇水周期，单位为天，必填。
- `fertilizingIntervalDays`：施肥周期，单位为天，可关闭。
- `nextWateringDate`：下次浇水日期。
- `nextFertilizingDate`：下次施肥日期，施肥关闭时为空。
- `careLogs`：历史记录列表。

每条历史记录包含：

- `id`：唯一标识。
- `plantId`：所属花草 ID。
- `type`：`watering` 或 `fertilizing`。
- `date`：记录日期。

## 日期计算规则

- 新增花草时，以当天作为初始基准日期。
- 设置浇水周期为 N 天时，下次浇水日期为今天 + N 天。
- 设置施肥周期为 N 天时，下次施肥日期为今天 + N 天。
- 点击“已浇水”后，生成当天浇水记录，并将下次浇水日期更新为今天 + 浇水周期。
- 点击“已施肥”后，生成当天施肥记录，并将下次施肥日期更新为今天 + 施肥周期。
- 逾期任务完成后，也按今天 + 周期重新计算，不按原计划日期补算。
- 如果同一天重复记录同一盆花的同一种养护，需要提示用户今天已记录过，确认后才再次记录。

## 任务分组规则

首页基于下次日期生成养护任务：

- 逾期：下次日期早于今天。
- 今天：下次日期等于今天。
- 未来 3 天：下次日期晚于今天，且在未来 3 天内。

同一盆花如果浇水和施肥都符合条件，需要显示两条任务，分别完成。

## 空状态

- 没有花草时：首页提示“先添加第一盆花吧”。
- 某个分组没有任务时：显示“这几天它们都还好”一类轻量文案。

## 视觉风格

视觉采用手账风，但保持 H5 轻量可用，并以手机端使用为第一优先级。

方向：

- 背景使用米白、浅绿、淡黄等柔和色。
- 卡片带圆角和轻微阴影，像贴在手账页上的纸片。
- 逾期任务使用温和橘色或珊瑚色，不使用强烈红色。
- 图标使用水滴、叶子、肥料袋等简单符号。
- 有图片时展示图片；无图片时展示默认植物插画或色块。

## 移动端适配

- 页面按手机端 H5 设计，主体宽度适配 320px 到 430px 常见屏幕。
- 任务列表、花草档案、详情页默认采用单列布局，避免手机上信息拥挤。
- 底部导航固定在屏幕底部，并适配 iPhone 安全区。
- 主要按钮和可点击卡片的触控高度不低于 44px。
- 表单输入框使用整行布局，便于单手填写。
- 图片在列表中使用小比例预览，在详情页使用更大的横向预览。

## 导航

底部导航包含两个 Tab：

- 今日照顾。
- 花草档案。

详情页从首页任务或档案卡片进入，不单独放入底部导航。

## 本地存储

MVP 使用浏览器本地存储保存数据。刷新页面后数据仍然保留，但换设备、换浏览器或清理缓存会导致数据不可用。

## MVP 范围

包含：

- 新增花草。
- 编辑花草。
- 可选上传图片。
- 设置浇水周期。
- 设置施肥周期，且允许关闭施肥。
- 自动计算下次浇水和施肥日期。
- 首页按逾期、今天、未来 3 天切换查看任务。
- 首页一键记录浇水或施肥。
- 详情页记录浇水或施肥。
- 详情页查看历史记录。
- 数据本地保存。

不包含：

- 登录和多设备同步。
- 微信或系统通知。
- 复杂统计报表。
- 位置、备注、标签、自定义字段。
- 社区分享或图鉴功能。

## 验证范围

需要验证：

- 新增花后，下次浇水和施肥日期正确生成。
- 首页三个分组能按当前日期正确筛选任务。
- 逾期任务完成后，按今天 + 周期重新计算。
- 同一盆花同时需要浇水和施肥时，显示两条任务。
- 首页完成任务后，详情页历史记录同步更新。
- 详情页完成任务后，首页任务状态同步更新。
- 刷新页面后，本地数据仍然存在。
- 同一天重复记录同一种养护时，会提示确认。
